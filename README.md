# 電子書下載寶庫

![GitHub](https://img.shields.io/github/license/jbiaojerry/ebook-treasure-chest)
![GitHub stars](https://img.shields.io/github/stars/jbiaojerry/ebook-treasure-chest?style=social)

> **🌐 [在線訪問 GitHub Pages](https://jbiaojerry.github.io/ebook-treasure-chest/)** - 體驗強大的實時搜索功能和多關鍵字搜索，快速找到你想要的電子書！

歡迎來到電子書下載寶庫，一個匯聚了各類電子書下載鏈接的地方。無論你是喜歡閱讀經典文學、經管勵志、終身學習、職場創業、技術手冊還是其他類型的書籍，這裡都能滿足你的需求。
該庫涵蓋了帆書app(原樊登讀書)、微信讀書、京東讀書、喜馬拉雅等讀書app的大部分電子書。

## 簡介

我們從各個電子書網站上精心收集了各種電子書下載鏈接，並根據常用的標籤對它們進行了簡單分類。每本書都包括了三種常見格式文件：epub、mobi 和 azw3，以滿足不同閱讀設備和喜好的需求。

## 🔍 如何使用

瀏覽我們的下載寶庫非常簡單：

### 🌐 實時快速搜索（推薦）

**訪問 [GitHub Pages 實時在線搜索頁面](https://jbiaojerry.github.io/ebook-treasure-chest/)**，體驗強大的實時快速搜索和多關鍵詞搜索功能：

- **🔎 實時搜索**：輸入書名、作者或分類關鍵詞，即時顯示匹配結果
- **💡 多關鍵詞搜索**：支持同時搜索多個關鍵詞（用空格分隔）

![搜索功能演示](.github/search-demo.gif?v=2)

### 💡 搜索技巧
- **在線搜索**：訪問 GitHub Pages 頁面，使用實時搜索功能（推薦）
- **Ctrl+F**：在 GitHub 頁面使用瀏覽器搜索功能
- **熱門分類**：文學、歷史、科普、管理、社會、推理等
- **按需查找**：職場、創業、技術、投資、心理學等專業領域
